# dm1q 驱动适配清单

更新：2026-11-07。适用范围：SM-S9110、CHC、FZI1、board revision 14。

**所有 HakiOS 设备功能均未在本机验证。设备树里有节点、Android 下正常工作或上游参考机已有驱动，都不能替代本机验收。**

参考源码固定为 HakiOS `63fc2b4633bac3af8e57dadab9f5a8d4cb940438`。原厂资料来自已校验 FZI1 包，base DTB 0 + DTBO 6；树不含启动时 fixup。

| 功能 | S23 已有证据 | 与参考机/上游的差异 | 下一项可验收结果 |
|---|---|---|---|
| 启动准入 | 精确 ABL 正常 OEM 门控返回 0，实机锁定 | 上游移植需要可执行自定义启动链 | 本型号本代可复现准入方式；当前阻塞 |
| UEFI/loader | 原厂模块目录、两份嵌入内存配置已解析 | dm2q 只作参考；上游 loader 仅 qemu/redwood，按特定 framebuffer 地址选板 | dm1q UEFI 输出与退出返回原系统 |
| CPU | 静态 MPIDR 0x0..0x700、PSCI，capacity 3×820/4×1800/1×1894 | 不能套用 redwood 四小核掩码、调频与电源控制 | 单核首条日志，再核对 MIDR/PSCI 与多核 |
| 中断/计时 | GICD 0x17100000、GICR 0x17180000，stride 0x40000；19.2MHz，虚拟 PPI11 | redwood GIC 地址不同 | 定时器计数与中断持续正常 |
| 显示 | 静态默认面板 phandle 指向 DM1_S6E3FAC_AMB606AW01，树还保留多个候选 | framebuffer、GOP、stride、格式与实际面板状态未采集 | UEFI GOP 画面，退出后原屏正常 |
| 触控 | `stm,stm_ts_spi`，SPI 控制器 0xa90000，静态 status=ok | 参考 `hakios.goodix.c` 为 GT9916/FT3680，寄存器协议、供电、引脚不同 | 先只读识别，再单点/多点坐标和休眠唤醒 |
| 按键 | 原厂 ButtonsDxe 可定位 | GPIO/PMIC 事件与参考机不能直接共享 | 电源/音量事件及释放状态 |
| GPU | Android sysfs 实读 Adreno740v2；树为 gen7-2-1，GPU 0x3d00000 | `hakios.adreno.c` 面向 Adreno642L，固件、GMU、SMMU 与寄存器均需复核 | 先软件显示，后 GPU 分步验收 |
| 存储 | UFS 0x1d84000，ICE 0x1d88000，HWKM 0x1d90000 | PHY/时钟/加密状态及 UEFI BlockIO 未验证 | 枚举与只读校验；任何写入另设门槛 |
| USB | DWC3 0xa600000；MAX77705/PD 静态节点 | 角色切换、供电、PHY 和原厂 UEFI 服务未验证 | 稳定枚举与可回收日志通道 |

| 音频 | 双 Cirrus CS35L43，I2C 0x41/0x40；LPASS/ADSP 树资料 | `hakios.speaker.c` 参考 AW88261，协议、DSP 与扬声器保护不同 | 音频链路及校准/保护核查后再做低音量输出 |
| 振动 | Cirrus CS40L26A 静态节点 | `hakios.haptic.c` 参考 AW86927，不能套用波形/驱动电平 | 芯片识别、固件与马达参数核对 |
| 电池/充电/温控 | MAX77705 等静态电源节点；尚无本机 HakiOS 测量 | ADSP、PMIC、充电和温控需独立验证 | 可信电量/温度、充电和限温行为 |
| 蜂窝/短信 | modem 保留内存、IPA/GSI 等静态资料 | 上游 IPA 4.11 假设与本机树偏移不同；MPSS PAS 未定位 | modem 启动、注册、收发与重启恢复；当前无接码能力证据 |
| 相机/指纹/传感器 | 本轮未完成精确器件与运行链路梳理 | 不根据同 SoC 或候选节点宣称支持 | 后续独立列验收，当前 missing |

## 自动参数提取的两个陷阱

上游 `tools/soc-args.py` 按精确节点叶名查找，生成 12/16 参数。三个“未找到”不是树里没有保留区：

| 参数意图 | 原厂节点 | `reg` 基址 | 状态 |
|---|---|---|---|
| command DB | aop_cmd_db_region@81c60000 | 0x81c60000 | 静态候选，未激活 |
| modem 内存 | mpss_region@89800000 | **0x8a800000** | 节点名地址与 reg 不同，以 reg 记录；未激活 |
| IPA GSI 固件保留区 | ipa_gsi_region@9b090000 | 0x9b090000 | 静态候选，未激活 |
| MPSS PAS | 未找到匹配属性 | 未知 | 不能沿用参考机默认值 |

IPA `reg` 起点为 0x3e00000；工具第132行固定加 0x40000，生成 0x3e40000。但本机树同时声明 `qcom,ipa-cfg-offset=0x140000`，两者存在明确差异。按属性相加得到的 0x3f40000 也只是候选，尚未经运行或本机内核源码交叉验收；不是“已修好的地址”。`qcom,ipa-hw-ver` 原始枚举为 0x18，本轮没有解析它的版本含义。

详细原始属性摘要见 [soc-extraction-review.json](soc-extraction-review.json)。自动生成的 soc.args 仅在私有 work 中研究，没有复制到活跃设备目录。当前 `CONFIG_FIRMWARE=none`、`cpus=1`，25 个驱动继续关闭。

## 可以提升支持状态的证据

`device.conf` 的 missing 只能在对应实机验收后调整。最低需要记录启动镜像和源码哈希、准确型号/板修订、步骤、日志、成功行为与退出/恢复结果。离线配置检查、编译、模拟器画面或原厂 Android 正常运行均不能代替。
